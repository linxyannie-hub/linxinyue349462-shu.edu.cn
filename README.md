# 直渠握手 · 优质代理推荐工作台

一个单文件、无需构建的浏览器端工作台，用于展示渠道/代理商候选信息、匹配评分、证据依据与推荐结果。项目适合产品演示、方案评审和静态部署。

## 在线运行

直接双击 `index.html`，或使用任意静态文件服务器打开：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 项目结构

```text
.
├── index.html                         # 工作台入口（由原始 HTML 整理）
├── 直渠握手优质代理推荐工作台.html       # 原始中文文件名版本
└── README.md
```

## 主要特点

- 单文件 HTML，CSS 与 JavaScript 内嵌，无需 Node.js、数据库或后端服务
- 响应式工作台布局，适合桌面端演示
- 代理候选卡片、匹配分、能力标签与证据优先的推荐信息
- 使用浏览器原生能力运行，便于部署到 GitHub Pages、Nginx 或任意静态托管服务

## 注意事项

- 页面引用了一个外部统计脚本以及介绍页链接；如果需要完全离线运行，请移除对应外部资源或替换为本地文件。
- 当前版本是前端演示原型，不包含真实账号体系、服务端数据持久化和权限控制。
- 部署到公开仓库前，请检查页面中是否包含不应公开的业务数据、联系方式或第三方链接。

## 部署到 GitHub Pages

1. 将 `index.html` 放在仓库根目录。
2. 在仓库 `Settings → Pages` 中选择 `Deploy from a branch`。
3. 选择 `main` 分支和 `/ (root)` 目录并保存。
